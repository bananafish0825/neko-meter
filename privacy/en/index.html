Neko Meter Privacy Policy

Last updated: 2026-10-25

日本語

Summary

Neko Meter does not connect to the internet. It does not collect, transmit, or share personal information with anyone. There are no accounts, no ads, and no analytics.

Information we do not collect

Neko Meter does not read, collect, or transmit your name, email address, postal address, phone number, location, contacts, photos, browsing history, keystrokes, or screen contents.

What is read on your device only

For the cat's behaviour and the icon's tooltip (the numbers shown when you hover over it), the app reads the following values (once per second unless noted). Each is used on the spot and is never stored or transmitted.

  • CPU usage (the delta from os.cpus())
  • Whether the PC is on AC power or on battery
  • Battery charge level, whether it is charging, and an estimate of the time left
  • Memory usage (os.freemem() and os.totalmem())
  • GPU usage and network download and upload speed (every 2 seconds, with Windows' typeperf; per-process GPU values are only added up. The app does not read what is sent or where it goes)
  • Free space on the C: drive (every 5 minutes)
  • The name of the running app and its CPU and memory use (only while the cat is running because of load: when it starts running and then every 60 seconds, with Windows' typeperf. The executable name of the heaviest app is shown in the tooltip and notification. It is only displayed — never stored, transmitted, or kept in the daily history. The app does not read window titles, open files, or what is inside an app)
  • How many seconds the keyboard and mouse have been idle (the Windows idle time; the app does not capture which keys are pressed)
  • Whether a new version downloaded by the Microsoft Store is waiting to be installed (Microsoft Store version only: 1 minute after start and then every 3 hours, the app reads the app-registration records in the Windows event log "Microsoft-Windows-AppXDeploymentServer/Operational". Only Neko Meter's own records are used; records about other apps are discarded)

These are device-wide values provided by Windows. None of them identifies a person.

What is stored on your device only

The app saves a single settings file on your device, at %APPDATA%\NekoMeter\save.json (in the per-package location on the Microsoft Store version).

It contains only these nine values (all are on/off, choice or language settings):

  • whether the cat is hidden (hidden)
  • whether the app starts with Windows (openAtLogin)
  • the display language (language: one of the 13 languages ja, en, zh, zh-TW, ko, es, ar, fr, de, pt-BR, it, ru or tr)
  • whether the first-run notice has been shown (noticeShown)
  • which load makes the cat run (loadSource: max, cpu, gpu or memory)
  • whether each notification is on (notifyBattery, notifyLoad, notifyDisk)
  • whether the heavy app's name is shown (showHeavyApp; the name itself is not stored)

It contains no personal information. Uninstalling the app or deleting this file removes it.

Only when you choose "Update and restart" in the menu on the Microsoft Store version, the result is written to a temporary file, store-update.json (in the per-package LocalState folder). It contains only the time, Neko Meter's package name, whether the update was installed, whether the app was restarted, and the Windows error message if something failed. The cat reads it the next time it starts and deletes it right away.

Sharing with third parties

None. The app contains no code for any external server or service to send data to.

Security

Because no data leaves your device, there is no transmission to encrypt. The settings file is kept in a location protected by your Windows user account.

Children's information

Neko Meter never asks for an age or any personal information, and does not collect personal information from children.

Contact

For questions about Neko Meter, please contact nekometer.support@gmail.com.

Changes

If this policy changes, the "Last updated" date above is revised. If a new feature changes what the app handles, the updated policy is published before that version is submitted.
