Neko Meter Privacy Policy

Last updated: 2026-09-22

日本語

Summary

Neko Meter does not connect to the internet. It does not collect, transmit, or share personal information with anyone. There are no accounts, no ads, and no analytics.

Information we do not collect

Neko Meter does not read, collect, or transmit your name, email address, postal address, phone number, location, contacts, photos, browsing history, keystrokes, or screen contents.

What is read on your device only

To decide how the cat behaves, the app reads the following values once per second. Each is used on the spot and is never stored or transmitted.

  • CPU usage (the delta from os.cpus())
  • Whether the PC is on AC power or on battery
  • Battery charge level and whether it is charging
  • How many seconds the keyboard and mouse have been idle (the Windows idle time; the app does not capture which keys are pressed)

These are device-wide values provided by Windows. None of them identifies a person.

What is stored on your device only

The app saves a single settings file on your device, at %APPDATA%\NekoMeter\save.json (in the per-package location on the Microsoft Store version).

It contains only these four values:

  • whether the cat is hidden (hidden)
  • whether the app starts with Windows (openAtLogin)
  • the display language (language, either ja or en)
  • whether the first-run notice has been shown (noticeShown)

It contains no personal information. Uninstalling the app or deleting this file removes it.

Sharing with third parties

None. The app contains no code for any external server or service to send data to.

Security

Because no data leaves your device, there is no transmission to encrypt. The settings file is kept in a location protected by your Windows user account.

Children's information

Neko Meter never asks for an age or any personal information, and does not collect personal information from children.

Contact

For questions about Neko Meter, please contact nekometer.support@gmail.com.

Changes

If this policy changes, the "Last updated" date above is revised. If a new feature changes what the app handles, the updated policy is published before that version is submitted.
